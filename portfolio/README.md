# BELINTAN B. — Personal Portfolio

Official engineering portfolio of **Belintan B.** — MBA Graduate, Certified Frontend Developer, Network Technical Support (Backend) Engineer, and AI-Powered Web Solutions specialist based in Tuticorin, Tamil Nadu, India.

---

## 🌟 Highlights & Architecture

- **100% Self-Contained & Offline-Ready:** All custom fonts (**Amarante** & **Redaction**), images, resume PDF, and icons are embedded directly via Base64 data URIs. No external CDN or internet connection is required to render.
- **5 Sequential Chapters:**
  1. **Chapter 01 · About the Engineer:** Professional bio, MBA credentials, skill matrix, and interactive WebGL2 particle swarm.
  2. **Chapter 02 · Services & Capabilities:** Enterprise web development, Java & Spring Boot backend systems, customer care track record, and guaranteed **50% OFF quote**.
  3. **Chapter 03 · Selected Projects:** Interactive project showcases with clean clickable preview bars & React Bits Pro DTC Ecommerce Brand modal preview.
  4. **Chapter 04 · Packages & Estimator:** Fixed pricing packages, exclusive web bundles, and an interactive cost calculator with instant WhatsApp lead export.
  5. **Chapter 05 · Inquiries & Engagements:** Direct channels, responsive consultation card, and expert contact bar with verified email and mobile information.
- **Apple Dark / Light System:** Native theme toggle with automatic persistence via `localStorage`.
- **Responsive Layout:** Optimized for mobile phones, tablets, and wide screens with CSS safe-area insets.

## 🚀 How to View

### Option 1: Direct File Launch (No Server Required)
Simply double-click `index.html` to open it in any web browser (`file:///`). All typography, particle effects, and interactive features work out-of-the-box.

### Option 2: Local HTTP Server (Port 8000)
Run the bundled PowerShell script:
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```
Then navigate to:
**[http://localhost:8000/](http://localhost:8000/)**
